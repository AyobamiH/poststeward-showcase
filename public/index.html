The problem

Agents are getting more capable.
External effects need to get more accountable.

A social API call is not just another tool invocation. It creates a public, durable effect under a real account identity.

PostSteward separates what an agent wants to do from what the owner actually authorises, then preserves enough evidence to inspect what happened afterwards.
